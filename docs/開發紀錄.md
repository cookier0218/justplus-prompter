# JustPlus 提詞機 — 開發紀錄

> 給 YouTube 拍片用、裝在 iPad 上的自製提詞機。此文件記錄需求、決策與已完成的工作。

---

## 專案目標

市面上的提詞機 App 多半要月費、介面雜、或廣告多。需求其實單純：把腳本放上去、順順地捲、iPad 上看得清楚。所以自己做一個貼身的。

- **裝置**：iPad（夾在攝影機旁邊，照著腳本拍 YouTube）
- **使用者**：Kris（惟家 JustPlus）

---

## 需求決策（2026-09-26 對齊）

| 項目 | 決定 | 理由 |
|---|---|---|
| 技術形式 | **網頁版**（iPad Safari 開網址） | 免上架、免 Apple 開發者帳號、改版快 |
| 擺放方式 | **直接夾攝影機旁邊讀**（文字正常顯示） | 最簡單；日後升級分光鏡再開鏡像 |
| 控制方式 | **藍牙遙控器 / 翻頁筆** | 單人拍攝不用碰螢幕 |
| 腳本來源 | **直接貼上文字** | 最直接；多份腳本存檔列為未來功能 |
| 品牌配色 | **惟家代表色 `#578d73`（墨綠）** | 與官網視覺一致 |

## 已完成的工作

### 1. 提詞機本體（單一 `index.html`）
- **編輯畫面**：貼腳本、可調字級 / 捲動速度 / 左右邊界，設定存 `localStorage`（下次打開還在）。
- **提詞畫面**：全螢幕大字往上捲。
  - 點畫面任一處 = 播放 / 暫停；播放後控制列自動淡出。
  - 底部控制：速度 ±、字級 ±、回開頭、編輯。
  - 中間淡綠色**閱讀指示線**幫定位視線。
  - **Wake Lock 防止 iPad 休眠**（加到主畫面時最有效）。
  - **水平鏡像開關**（分光鏡玻璃架構預留，目前預設關）。

### 2. 藍牙遙控器支援
把翻頁筆/遙控器當藍牙鍵盤，接收並對應按鍵：

| 遙控器按鍵（送出） | 提詞機動作 |
|---|---|
| 前進 / → / PageDown / 空白 / Enter | 播放 ⇄ 暫停 |
| 後退 / ← / PageUp | 退回重讀（暫停並往回捲一段） |
| ↑ / ↓ | 加速 / 減速 |
| Esc | 離開提詞畫面 |

> ⚠️ 網頁**抓不到音量鍵**，所以只送音量鍵的「自拍快門遙控器」不能用。要買會送方向鍵/翻頁鍵的（簡報筆最穩）。

### 3. 遙控器按鍵測試模式
編輯畫面的「🎮 測試遙控器按鍵」——按遙控器即時顯示送出的按鍵名稱 + 對應動作，用來驗證新遙控器能不能用、鍵位對不對。

### 4. 品牌配色
從官網 `shop.justplus.com.tw` CSS 撈出色票，套惟家代表色：
- 背景：深墨綠 `#0d1a16`
- 按鈕（開始/播放/實心）：代表色 `#578d73`
- 指示線 / highlight：亮版 `#7cbfa3`

### 5. 部署上線
- **GitHub repo**（公開）：https://github.com/cookier0218/justplus-prompter
- **線上網址**：https://cookier0218.github.io/justplus-prompter/
- 托管：GitHub Pages（免費，main branch 根目錄），push 後約 1 分鐘自動部署。

## 硬體：藍牙遙控器

- **已訂購：Logitech 羅技 R500s**（藍牙簡報筆，iPad 直連不用轉接）。
- 預期鍵位：前進＝Page Down（播放/暫停）、後退＝Page Up（退回重讀）。
- ⚠️ R500s 最下面「開始/結束簡報」鍵會送 **Esc**（＝離開提詞畫面），正常只用前進/後退兩顆即可。
- 到貨後用「🎮 測試模式」驗證實際鍵位；若不符再調整對應。

## iPad 使用方式

1. Safari 開 https://cookier0218.github.io/justplus-prompter/
2. 分享 → **加入主畫面** → 從主畫面開就是全螢幕 App（防休眠才生效）。

## 怎麼改功能

程式碼是單一 `index.html`（HTML+CSS+JS 全在一起）。改法：修改 → commit → `git push origin main` → GitHub Pages 約 1 分鐘後自動更新。iPad 端下拉重新整理（或關掉主畫面 App 重開）即拿到新版。
