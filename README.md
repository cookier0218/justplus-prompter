# JustPlus 提詞機

給 iPad 用的網頁版提詞機。單一 `index.html`，Safari 打開就能用，免安裝、免月費、免廣告。

## 怎麼弄到 iPad 上

三選一，由簡到進階：

1. **AirDrop（最快試用）**：把 `index.html` AirDrop 到 iPad → 用 Safari 開啟。
   - 缺點：檔案版無法「加入主畫面」全螢幕、防休眠也可能失效。適合先試感覺。
2. **放到網路上（推薦，正式用）**：丟到任何靜態空間都行——GitHub Pages、Netlify、Cloudflare Pages、或自己的網站（例如 `prompter.justplus.com.tw`）。開網址後：
   - Safari → 分享 → **加入主畫面** → 從主畫面開啟就是全螢幕 App，防休眠、遙控器都正常。
3. **本機測試**：電腦上直接雙擊 `index.html` 即可。

## 藍牙遙控器 / 翻頁筆

隨便一支便宜的翻頁筆或藍牙拍照遙控器（NT$200-400）都可以，它們對 iPad 來說就是「藍牙鍵盤」。按鍵對應：

| 按鍵（遙控器常送這些） | 動作 |
|---|---|
| 前進 / 空白 / Enter / → / PageDown | 播放 ⇄ 暫停 |
| 後退 / ← / PageUp | 暫停並退回一段重讀 |
| ↑ / ↓ | 加速 / 減速 |

> ⚠️ 有些遙控器送的是「音量鍵」，網頁抓不到。買的時候選標示「翻頁」「拍照快門」的，或到手後用電腦開網頁按按看有沒有反應。

## 操作

- **編輯畫面**：貼腳本、調字級 / 速度 / 邊界，設定會自動記住（存在瀏覽器）。
- **提詞畫面**：點畫面任一處 = 播放/暫停；播放後控制列會自動淡出；底部有速度、字級、回開頭、編輯按鈕。
- **鏡像**：若日後升級成分光鏡（提詞玻璃）架構，開「水平鏡像」文字就會左右翻轉。目前直接夾攝影機旁邊讀 → 保持「關」。
